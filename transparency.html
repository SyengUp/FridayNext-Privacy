透明度

最后更新日期：2026年7月28日

你把 AI 助手接进了自己的生活，然后让它的流量经过我们的服务器。这一页说清楚我们能看到什么、看不到什么，以及为什么你不必仅凭一句承诺来相信这件事。

一句话

FridayTunnel 是一根管道，不是一个中间人。你的对话在离开 iPhone 前就已加密，到你自己的网关才解开——我们手里从来没有能打开它的钥匙。

我们看不到什么

对话内容、你输入的提示词、Agent 调用工具的结果、附件的内容和文件名、你的网关访问令牌、Agent 配置、历史会话。

这不是因为我们承诺不看，而是因为我们看不了。加密的两端分别是你的 iPhone 和你自己那台机器，密钥只在这两头，中继在中间只负责把加密后的字节转过去。

我们看得到什么

说实话，端到端加密藏不住一切。为了把流量送到正确的地方，中继必须知道：

  • 你的设备和网关的 IP 地址
  • 什么时间连接、连了多久
  • 要送往哪个子域名
  • 传了多少字节
  • 连接成功还是失败

这些叫元数据。任何转发流量的服务都必须处理它们，无论宣传得多么私密。我们不用它们做画像或广告，不出售，也不提供给第三方——但我们不假装它们不存在。

附件为什么也是安全的

大文件不走中继（那样太慢），而是直传对象存储。但它在离开你的设备之前就已经用一次性密钥加密了，密钥经加密通道单独交给对端。存储那边只有一堆无意义的字节和一个随机文件名——连原始文件名都看不到。

加密还带完整性保护：如果密文在传输或存储中被改动过一个字节，解密会直接失败，而不是给你一个悄悄坏掉的文件。

为什么服务器被攻破也读不到你的数据

假设有人完全控制了我们的服务器。他们能做的是：让服务不可用、看到上面那些元数据、撤销你的公网授权。

他们做不到的是解密你的流量——密钥不在服务器上。他们也无法伪装成你的网关来骗你的 App 交出数据：App 在配对时记住了你网关的公钥指纹，之后每次连接都核对，不匹配就直接断开，不降级、也不弹窗问你要不要继续。

哪些风险仍然存在

没有系统是万无一失的。诚实列出我们知道的：

  • 元数据。如上所述，无法通过加密消除。
  • 第一次配对。指纹是在配对那一刻记住的。如果在你扫码的那一瞬间，有人已经同时控制了你的网络和你到网关的路径，理论上可能让你记住错误的指纹。配对完成之后这个窗口就关闭了。建议在家里的网络下完成首次配对。
  • 你的设备。会话记录保存在 iPhone 本地。如果手机没设密码又被人拿到，本地数据是可读的——这跟手机上的其他应用一样。请设置密码和面容 ID。
  • 你自己的网关。数据在你的机器上以明文存在，因为 Agent 需要读它。那台机器的安全由你负责。
  • 我们很小。FridayNext 由个人开发和运营，没有企业级的合规部门和值班团队。这正是我们把安全建立在架构上、而不是建立在「请相信我们」上的原因——即使我们犯错，你的内容依然是加密的。

你可以自己验证

运行在你自己网关上的那部分代码是公开的：openclaw-fridaynext-channel，其中包含附件加密的完整实现。上面关于加密的说法，你或任何懂行的人都可以直接对着代码核实，不必听我们自述。

我们没有通过任何外部安全认证，也不声称通过。等到订阅收入足以覆盖成本，我们会请第三方密码学审计机构做一次完整审查，并公开完整报告，包括查出来的问题。

发现漏洞怎么办

请私下告诉我们，不要公开发帖——那会让其他用户在修好之前暴露在风险中。

  • GitHub Security Advisory（首选）
  • 邮件 s826135274@icloud.com，主题写上 Security

我们会在 7 个工作日内回复，确认问题后 90 天内修复或公开说明如何规避。修好之后，如果你愿意具名，我们会在这一页致谢。这是个人项目，目前没有漏洞赏金，只有一句真诚的感谢。

举报滥用

如果有人拿 FridayTunnel 做坏事（发垃圾信息、扫描、钓鱼、转卖中继），请发邮件到 s826135274@icloud.com，主题写 Abuse，附上子域名和你观察到的情况。

需要说明的是：正因为我们读不到隧道里的内容，我们无法通过「检查那条隧道在传什么」来核实举报，只能依据流量特征和外部证据判断。查实的滥用会被撤销授权、断开隧道。反过来说，如果有人要求我们检查某位用户在传什么，我们同样做不到。

政府和执法请求

截至本页更新日期，我们没有收到过任何政府或执法机构的数据请求、保密令或数据留存要求。这句话会在每次更新时重新核对；如果它哪天消失了，请按字面理解。

即使收到合法请求，我们能交出的也只有实际持有的东西：订阅状态、设备授权记录、隧道信息、网络元数据。对话和附件内容不在其中——不是我们拒绝配合，是我们确实没有。

数据保存多久

  • 加密附件最多保存 7 天，由对象存储自动删除。
  • 服务器访问日志保留 14 天。
  • 控制面每日备份保留 14 天。
  • 已过期的设备授权记录保留 90 天，用于排查问题和安全审计。
  • 附件流量统计按自然月清零。
  • 安全审计记录只包含授权和配额事件，不含任何对话或附件内容。

为什么有限额

限额的目的是让隧道够你日常聊天用，同时无法被人拿去当廉价代理牟利——那会挤占其他用户的带宽，也会让服务撑不下去。

  • 每条隧道约 4 MB/s
  • 每个 Apple ID 最多 3 条隧道
  • 附件每月 3 GB（试用期 300 MB）
  • 单个附件最大 100 MB

对话和工具调用不单独限量。

我们的承诺

  • 不追踪。没有广告 SDK，没有第三方分析，没有行为埋点。
  • 不训练。不用你的任何数据训练模型。
  • 不出售。不卖数据，不给广告商。
  • 可以走。局域网连接永久免费。到期或退款只是停掉公网连接，你的会话、附件、配置一样不动——想换成 Tailscale 或自建方案随时可以。
