FridayNext 隐私政策

最后更新日期：2026年5月13日

FridayNext（以下简称「本应用」）是一款面向 OpenClaw 用户的自托管 AI 对话客户端。我们高度重视你的隐私。本隐私政策说明了本应用如何处理你的数据。

数据收集与存储

本应用不收集任何个人数据。所有对话内容、会话记录、附件及配置信息均存储在你的设备和/或你自己的 OpenClaw 服务器上。本应用的开发者无法访问、查看或收集你的任何对话数据或个人信息。

本应用不集成任何第三方分析 SDK、广告 SDK 或埋点服务。

网络通信

本应用仅与你指定的 OpenClaw 网关服务器进行通信。所有网络请求均直接在你的设备与你的服务器之间进行，不会经过任何第三方服务器。本应用不提供也不依赖任何云端中转服务。

设备权限使用说明

本应用会请求以下设备权限，所有权限均仅在功能需要时使用：

  • 麦克风 — 用于语音输入功能，将你说的话实时转录为文字。录音数据仅在本地处理，不会上传至任何服务器。
  • 语音识别 — 用于将语音转换为文字消息。识别过程由 iOS 系统提供，遵循 Apple 的隐私保护机制。
  • 相机 — 用于扫描 OpenClaw 网关配对二维码，以及在聊天中拍摄照片或扫描文档作为附件发送给 Agent。相机仅在你主动使用时开启。
  • 位置信息 — 仅在连接的 OpenClaw Agent 请求时获取一次位置信息。本应用不会在后台追踪你的位置。
  • 照片库（写入） — 仅用于将 Agent 生成的图片等内容保存到你的照片库。本应用不会读取你的照片库。

数据安全

对话记录以 JSONL 格式存储在设备本地。与网关之间的通信支持 TLS 加密及证书指纹绑定（TLS Pinning）。你应自行确保 OpenClaw 网关服务器的安全配置。

儿童隐私

本应用不面向 13 岁以下儿童，亦不会有意收集儿童的个人信息。

隐私政策更新

本隐私政策可能会不时更新。更新后的政策将发布在此页面，重大变更会通过应用更新说明告知。
