基础

FridayNext 是什么？

一个 iOS 客户端，连接你自己的 OpenClaw 网关。它本身不提供 AI 能力——模型、API Key、会话数据都在你自己的机器上，FridayNext 只是那台机器在你口袋里的入口。

我需要准备什么？

一台常开的机器（Mac、Linux 服务器、NAS 均可）跑 OpenClaw，以及你自己的模型 API Key。OpenClaw 见 openclaw.ai。FridayNext 不代售 API Key，也不代理模型调用。

需要付费吗？

局域网连接永久免费，不需要订阅、不需要账号。只有当你想在外面也能连回家里的网关，且不想自己折腾内网穿透时，才需要 FridayTunnel 订阅（¥38/年，含 2 周免费试用）。

支持哪些 iOS 版本？

iOS 26.0 及以上。

有 Android 版吗？

没有，目前仅 iOS。

FridayTunnel

它解决什么问题？

让你在外面能连回家里的网关，不用配端口映射、DDNS 或公网 IP。本质上是替你养一根隧道——¥38/年差不多正好是一台入门云服务器的促销年费。

你们能看到我的对话吗？

不能。隧道是端到端加密的，加密终点在你自己的网关上，中继按 TLS 的明文 SNI 字段路由、不解密。附件在客户端加密后才上传，密钥从不离开配对双方。详见透明度页，那里也诚实列出了我们确实能看到的东西（网络元数据）。

为什么不用 Tailscale 就好？

完全可以。Tailscale、frp、Cloudflare Tunnel、反向代理，FridayNext 都支持——只要设备能访问到网关即可。FridayTunnel 只是一个省事的默认选项，不是必需品。

试用多久？到期怎么办？

2 周，通过 Apple 标准免费试用提供，期间可随时取消不扣费。到期后隧道停止，但本地会话、附件、网关配置一律不动；回到 Wi-Fi 下照常使用，或换自建通道继续在外用。我们不做数据锁定。

一个订阅能用几台设备？

订阅绑 Apple ID，名下设备共享。隧道上限 3 条/Apple ID（一条隧道 = 一个 Apple ID 到一个网关的公网路由）。

有流量限制吗？

对话和工具调用没有单独限额。附件走对象存储旁路，订阅期每月 3 GB、试用期 300 MB，单个文件上限 100 MB。超出后附件收发受限，但对话不受影响，次月自动重置。

配对与连接

怎么配对？

在网关上运行 npx -y @syengup/friday-channel-next 生成配对二维码，用 App 扫描。二维码 10 分钟有效、一次性使用，扫过即作废。

扫码后连不上

常见原因：设备与网关不在同一局域网且尚未订阅 FridayTunnel；网关未运行或网络不通；二维码已超过 10 分钟。先在同一 Wi-Fi 下重新生成二维码并尽快扫描。

局域网正常，出门连不上

确认网关保持开机联网，然后在连接页查看 FridayTunnel 状态。未订阅、已到期、已退款，或网关端插件版本过旧都会导致公网连接不建立——插件升级同样是 npx -y @syengup/friday-channel-next。

能配对多个网关吗？

可以，在连接页切换，同一时间连接一个。

订阅与退款

买了但状态没更新

保持联网、重新打开订阅页等待同步。仍未生效可点「恢复购买」（不会重复扣费）或重启应用。

什么时候用「恢复购买」？

换设备、重装应用，或 App Store 显示有效订阅但应用没识别时。它不会创建新订阅。

怎么取消或退款？

取消续订：iPhone「设置」→ Apple 账户 → 订阅。退款：reportaproblem.apple.com，是否批准由 Apple 决定。退款后公网授权会被撤销，本地数据不受影响。

安全与隐私

数据存在哪？

会话、网关配置、附件缓存、证书指纹都在设备本地（iOS 沙盒 + iCloud 加密备份），不上传。订阅 FridayTunnel 后，控制面另存假名标识（随机 UUID）、订阅状态、设备授权和必要网络元数据——不含内容。

会收集使用数据或崩溃报告吗？

不会。没有第三方分析、埋点或崩溃上报 SDK。遇到问题需要你主动反馈。

设备丢了怎么办？

用「查找」远程抹除可清除本地数据。网关上的副本由你自己管理。过期的设备授权 90 天后自动清理。

怎么报告安全漏洞？

走 GitHub Security Advisory 私密报告，请勿公开提 Issue。详见透明度页。

开源

哪些部分开源了？

网关插件已开源：openclaw-fridaynext-channel，包含附件加密的完整实现，加密声明可直接对着代码核。iOS 应用与控制面尚未开源。

能贡献吗？

欢迎，请到插件仓库提 Issue 或 PR。
