入门

FridayNext 是什么？

它是你自己那台电脑上的 AI 助手在 iPhone 上的入口。模型、API Key、所有对话记录都在你自己的机器里，FridayNext 只是让你在手机上跟它说话。

换句话说，它不是又一个 AI 聊天 App——它是你的 AI 的遥控器。电脑那头跑的是 OpenClaw，一个开源的 AI Agent 网关。

需要付费吗？

在家里连自己的网关：永久免费，不需要账号，不需要订阅。

出门在外还想连回家：这需要一条公网通道。你可以自己配 Tailscale 或反向代理（也是免费的），或者订阅 FridayTunnel 让我们替你搞定（¥68/年，含 2 周免费试用）。

支持哪些设备？

iPhone，iOS 26.0 及以上。暂无 Android 版。

FridayTunnel

它到底做什么？

让你在外面能连回家里的网关，不用配端口映射、不用 DDNS、不用公网 IP、不用碰路由器设置。

本质上是我们替你养一根隧道并保证它一直通着。¥68/年，大约每月 5.7 元。

你们能看到我的对话吗？

不能。对话在离开 iPhone 前就已加密，到你自己的网关才解开，中继在中间只转发密文。

需要说明的是，加密保护的是内容本身；像连接时间、流量大小这类网络层信息，任何转发流量的服务都必须处理。完整说明见隐私政策。

为什么不直接用 Tailscale？

完全可以，我们不拦着。Tailscale、frp、Cloudflare Tunnel、Nginx 反向代理，FridayNext 都支持——只要你的手机能访问到网关就行。

FridayTunnel 卖的是「不用管」：扫个码就通了，不用理解 NAT 穿透，也不用在换网络时排查为什么连不上。如果你享受折腾这些，那你确实不需要它。

试用怎么算？到期会怎样？

2 周免费试用，由 Apple 提供，期间随时取消不扣费。

到期后公网连接停止，但你的会话记录、附件、网关配置一样都不会动。回到家里的 Wi-Fi 照常用，或者换成自建通道继续在外面用。我们不做数据绑架。

有流量限制吗？

附件走单独通道，每月 3 GB。聊天和工具调用不限量。

连接与配对

怎么配对？

在跑 OpenClaw 的机器上运行 npx -y @syengup/friday-channel-next，按提示生成配对二维码，用 App 扫一下就好。

二维码 10 分钟内有效、只能用一次——扫过就作废，捡到的人也用不了。建议在家里的网络下完成首次配对。

扫码后连不上

按可能性从高到低：

  • 二维码超过 10 分钟了——重新生成一个。
  • 手机和电脑不在同一个 Wi-Fi 下，且还没订阅 FridayTunnel。
  • OpenClaw 没在运行，或者那台机器睡着了。
  • 路由器或防火墙拦了。

在家好用，出门就连不上

先确认电脑没休眠、网络正常，然后在 App 的连接页看 FridayTunnel 状态。

如果状态异常，通常是订阅未生效/已到期，或者网关上的插件版本太旧。升级插件同样是 npx -y @syengup/friday-channel-next。

订阅与退款

买了但显示未订阅

保持联网等一两分钟。还是不行就点「恢复购买」（不会重复扣费），或者重启 App。

什么时候需要「恢复购买」？

换了新手机、重装了 App，或者 App Store 显示有订阅但 App 没认出来。它只是重新同步状态，不会创建新订阅。

怎么取消或退款？

取消续订：iPhone「设置」→ 点你的头像 → 订阅 → FridayNext。取消后仍可用到当前周期结束。

退款：去 reportaproblem.apple.com 申请，批不批由 Apple 决定。退款后公网连接会停止，本地数据不受影响。

换 Apple ID 后订阅还在吗？

订阅跟着 Apple ID 走。换设备但用同一个 Apple ID，点「恢复购买」就能接着用；换成另一个 Apple ID 则需要重新订阅。

隐私与安全

我的数据存在哪？

会话记录、网关配置、附件缓存都在你的 iPhone 本地和你自己的网关上，不上传。

如果订阅了 FridayTunnel，我们的服务器上另有一个随机生成的匿名标识、订阅状态和设备授权记录——没有你的姓名、Apple ID、手机号或付款信息，Apple 也不会把这些给我们。

你们会收集使用数据或崩溃报告吗？

不会。没有第三方分析、没有埋点、没有崩溃上报。这也意味着出问题时我们完全依赖你告诉我们。

手机丢了怎么办？

用「查找」远程抹除即可清除本地数据。你电脑上的那份记录不受影响，由你自己管理。过期的设备授权 90 天后自动清理。

发现安全问题怎么反馈？

请走 GitHub Security Advisory 私下告诉我们，别公开发帖，详见技术支持页。
